# y2kdream — Warp Terminal Themes

Two scheme families: **Original** (dusty/eye-friendly) and **Euphoria** (vibrant pixel-dreamscape).
Each scheme: 6 color families × light + dark = 12 themes. Total: 24 .yaml files.

## Install

1. Copy the chosen `.yaml` files and matching `.svg` from `../backgrounds/` into `~/.warp/themes/`.
2. Open Warp → Settings → Appearance → Themes → pick your y2kdream variant.
