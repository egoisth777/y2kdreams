Install in Warp

Copy the chosen .yaml + the matching .svg background into Warp's themes folder, then pick the theme from Settings → Appearance.

# macOS / Linux
mkdir -p ~/.warp/themes
cp warp-themes/y2kdream-euphoria-rose-dark.yaml ~/.warp/themes/
cp backgrounds/euphoria-rose.svg ~/.warp/themes/
# open Warp → ⌘, → Appearance → Themes → "y2kdream Euphoria Rose Dark"
