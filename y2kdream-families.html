Install in Warp

Copy the chosen .yaml + the matching .svg background into Warp's themes folder, then pick the theme from Settings → Appearance.

# macOS / Linux
mkdir -p ~/.warp/themes
cp warp-themes/y2kdream-forest-dark.yaml ~/.warp/themes/
cp backgrounds/forest.svg ~/.warp/themes/
# open Warp → ⌘, → Appearance → Themes → "y2kdream Forest Dark"
